# 3+1D UPPE 包络求解器（成丝优化版）

## 技术路径

**SVEA（慢变包络近似）+ 复包络 + UPPE 单向传播方程**

- 将电场分解为载波 × 复包络：E(t) = Re[A(t) · exp(-iω₀t)]
- 只求解包络 A(t)，不分辨光学周期，适合 ≥50fs 脉冲
- 坐标变换到群速度参考系，脉冲始终保持在时间窗口中心

## 数值方法

### ERK4(3)IP — 嵌入式龙格-库塔 4 阶 + 相互作用绘景

- 线性步（色散+衍射）：频域精确乘法，使用平方差公式消除 kz - k_ref 的灾难性相消
- 非线性步：4 阶 RK 子步，在 3D 实空间计算
- 相互作用绘景（IP）：L_step + N_func 交错，避免算子分裂误差
- 嵌入式误差估计：用 3 阶结果 A3 与 4 阶结果 A4 之差控制步长

### 自适应步长

- **L∞ 范数误差估计**：`err = max|A4 - A3| / max|A4|`
- 成丝场景关键设计——L2 范数会被低能量背景稀释误差，导致步长不当放大
- 缩放因子：`h_new = h × 0.95 × (tol/err)^0.2`

## 物理模型

### 非线性极化（Kerr + 拉曼）
- χ⁽³⁾ Kerr 效应：PNL ∝ n₂ · I · A
- 拉曼响应：零填充法（2×Nt），确保因果性不被周期边界破坏
- 自陡峭算子 (1 + ω/ω₀) **仅作用于 Kerr 极化**，等离子体项不受蓝移

### 等离子体引擎（CUDA Kernel）
- 电离率：Keldysh 公式 + MPI 查表
- 等离子体密度演化：精确指数积分 `ρ(t+dt) = ρ(t)·exp(Γdt) + S·(exp(Γdt)-1)/Γ`
- 中性分子耗尽：`depletion = (ρ_nt - ρ)/ρ_nt`
- 能量守恒：电离损耗 ∝ 真实的电子生成率

### 介质
- **FusedSilica**（熔融石英）：Sellmeier 色散 + n₂=3.0e-20 + 拉曼
- **Air**（空气）：压力可调 + 无拉曼 + 无雪崩电离

## 适用场景

- 飞秒激光成丝（filamentation）
- 多通池（MPC）非线性脉冲压缩
- 超连续谱产生
- 脉宽 ≥ 50fs 的传播问题
