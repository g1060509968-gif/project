# 3+1D UPPE 实场求解器（PPT 全量子电离版）

## 技术路径

**实场（Real Field）+ 全场 UPPE 方程（无包络近似）**

- 直接求解真实电场 E(t)，不分离载波与包络
- 能够分辨每个光学周期，保留 CEP（载波包络相位）信息
- 适用任意脉宽，包括少周期（<10fs）乃至亚周期脉冲

## 数值方法

### ERK4(3)IP + RFFT

- 时域使用实数 `rfft`，频域只存正频率（Nt/2+1 点），计算量和显存减半
- 线性步：频域精确乘法 `exp(Δz · D_operator)`，D_operator = -i(kz - k_ref)
- 非线性步：4 阶 RK + 相互作用绘景（同包络版）
- 降阶误差估计：用 2 阶半步结果代替 3 阶嵌入对，省去 1 次 N_func 调用
- **误差估计式**：`E_low = L_step(v_ip + h/2·α1 + h/2·α2, h/2)`，err = max|E4 - E_low| / max|E4|（L∞ 范数）

### 自适应步长
- 缩放因子：`h_new = h × 0.9 × (tol/err)^0.333`（适配降阶误差估计的阶数）

### 全场 UPPE 源项
- 直接使用麦克斯韦方程的极化+电流源项：
  - `∂zE = i·ω²/(2ε₀c²kz) · P_NL` — 非线性极化驱动
  - `∂zE = -ω/(2ε₀c²kz) · J` — 自由电流驱动
- DC 分量抹除以防止数值爆炸

## 物理模型

### 非线性极化
- **显式 χ⁽³⁾ 三阶极化率**：χ⁽³⁾ = (4/3)·c·ε₀·n₀²·n₂
- P_NL = ε₀·χ⁽³⁾·E³（纯 Kerr）或 ε₀·χ⁽³⁾·E·[(1-fR)·E² + fR·conv(E², h)]（Kerr + 拉曼）

### PPT 全量子电离模型
- **Perelomov-Popov-Terent'ev** 理论公式，替代简化的 Keldysh 模型
- 包含量子参数：有效电荷 Z、轨道角动量 l、磁量子数 m
- 15 个 ATI（阈上电离）光子吸收通道求和
- 自动覆盖隧穿区 → 多光子区全过渡段

### 等离子体电流引擎（CUDA Kernel）
- **自由电子 Drude 电流**：时域 ODE 精确解 `dJ/dt = -ν_c·J + (e²/m_e)·ρ·E`
- **电离损耗电流**：J_loss = (dρ/dt)·Ui / E（替代包络模型的等效吸收项）
- 总宏观电流 J = J_free + J_loss，直接馈入 UPPE 源项

### 介质
- **FusedSilica**（熔融石英）：Sellmeier + n₂=3.0e-20 + 拉曼 + Z=1, l=0, m=0
- **Air**（空气）：压力可调 + PPT 参数为 O₂ 分子等效

## 适用场景

- 少周期脉冲（<10fs）传播
- CEP 敏感过程（高次谐波、阿秒物理）
- 需要最高电离精度的成丝仿真
- 宽光谱（> 倍频程）场景

## 与包络版的对比

| | 包络版 (envelope) | 实场版 (real-field) |
|---|---|---|
| 场表示 | 复包络 A(t) | 真实电场 E(t) |
| 脉宽下限 | ~50fs | 无限制 |
| CEP 信息 | 丢失 | 保留 |
| 电离模型 | Keldysh | PPT 全量子 |
| FFT 类型 | c2c (复数) | r2c (实数) |
| 自陡峭 | 显式算子 | 方程内嵌 |
| 计算量 | Nt 复数点 | Nt/2+1 实数等效 |
