# 3+1D UPPE 实场求解器（PPT 全量子电离版）

## 技术路径

**实场（Real Field）+ 全场 UPPE 方程（无包络近似）**

- 直接求解真实电场 E(t)，保留 CEP 信息，适用任意脉宽
- 时域使用 `rfft`（实数→半复频谱），频域点数减半，天然无负频率
- 坐标变换到群速度参考系：`k_ref = k₁·ω`（纯延迟，无常数截距，保留 CEP）

## 数值方法

| 组件 | 方法 |
|------|------|
| 线性步 | `exp(Δz·D_op)`，`D_op = −i(kz−k_ref)` |
| 非线性步 | 4 阶 RK + 相互作用绘景，`ifft2→irfft→N_func→rfft→fft2` |
| 源项 | `∂E/∂z = … + UPPE_P_coeff × P_NL + UPPE_J_coeff × J` |
| 误差估计 | 2 阶半步法 vs 4 阶结果，L∞ 范数，省去 1 次 N_func |
| 步长控制 | `h_new = h × 0.9 × (tol/err)^0.333`，适配 2-vs-4 阶对比 |
| DC 保护 | P_coeff、J_coeff 在 ω=0 处置零 |

### UPPE 系数

```
P_coeff = −i·ω²/(2ε₀c²kz)      [极化驱动]
J_coeff = −ω/(2ε₀c²kz)         [电流驱动]
```

推导验证：与包络版 Kerr 系数 `i(ω₀/c)n₂` 一致，χ₃=(4/3)cε₀n₀²n₂。

## 物理模型

### 非线性极化
- 瞬时 Kerr：`P_NL = ((ε₀χ₃)·E)·E·E`（分步乘避免 E³ 中间溢出 float32）
- **HOKE**：`P_NL += ((ε₀χ₅)·E)·E²·E²`，χ₅=(4/5)c²ε₀²n₀³n₄
- 拉曼响应：2×Nt 零填充法
- 自陡峭：方程内嵌（ω²/kz 的频率依赖性），无需显式算子

### 等离子体电流引擎（CUDA RawKernel）
- **输入/输出**：float32 输入 → double 内部计算 → float64 输出
- **Drude 电流**：时域 ODE 精确解，`dJ/dt = −ν_cJ + (e²/m_e)ρE`
- **电离损耗电流**：`J_loss = true_gen_rate·Ui·E/E²`（含光电离 + 雪崩电离）
- 中性分子耗尽 + `gdt` 对称截断 ±10 + `fabs()` 替代 `abs()`

### 电离模型
- **PPT（Perelomov-Popov-Terent'ev）全量子模型**
- 输入：等效 CW 光强 `I_equiv = (1/2)ε₀cn₀E²`
- 包含量子参数 (Z, l, m)、ATI 15 通道求和、Keldysh γ 参数自动过渡
- a.u.↔SI 完整转换：E_a=5.14×10¹¹ V/m，t_a=2.42×10⁻¹⁷ s，E_h=27.21 eV

## 与包络版的差异

| | 包络版 | 实场版 |
|---|---|---|
| 场表示 | 复包络 A(t) | 实电场 E(t) |
| 频域 | fft（复数，Nt 点） | rfft（实数，Nt/2+1 点） |
| 脉宽下限 | ~50fs | 无限制 |
| CEP | 丢失 | 保留 |
| 电离 | Keldysh（近似） | PPT（全量子） |
| 自陡峭 | 显式 (1+ω/ω₀) 算子 | 方程内嵌 |
| 电流 | Drude 解析 | Drude ODE 时域解 |
| 误差估计 | 5 次 N_func/步 | 4 次 N_func/步 |

## 适用场景

- 少周期脉冲（<10fs）成丝
- CEP 敏感过程（高次谐波、阿秒物理）
- 宽光谱（> 倍频程）超连续谱
- 需要最高电离精度的气体成丝
